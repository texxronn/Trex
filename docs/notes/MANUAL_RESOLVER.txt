Manual Resolver is a "Admin Service"
Provides:
1. Web Interface
2. It is itself a transaction stream follower. Tails and scrapes the journal.
3. Presents a list of HELD & REVIEW transactions on the Web.
4. Provides a minimal (but double needs confirm) actions to either indicate confirm EXTERNAL, confirm REVIEW, review TRANSFER etc.
5. Basically provides manual interactivity.
6. The action will invoke an API call on sequencer.
7. Sequencer processes API call - generates transaction events - resolves sees them - and then automatically updates the web portal.
8. No authentication (for now)
